# 🛡️ ScamShield AI

**Multimodal AI-Powered Fraud, Phishing, Fake Certificate & Deepfake Detection Platform**

🔗 **Live Demo:** [https://scam-shield-ai-adf67.web.app](https://scam-shield-ai-adf67.web.app)

## 🚀 Overview
ScamShield AI helps users verify suspicious links, fraudulent job messages, forged academic/internship certificates, QR scams, and AI-manipulated deepfake videos in real time using Google's Gemini multimodal AI.

## ✨ Key Features
- **Multimodal Analysis:** Detects scams across **Text, URLs, Images (Certificates/QR codes), and Videos (Deepfakes)**.
- **High-Availability Model Fallback:** Automatically routes requests across `gemini-3.8-flash`, `gemini-3.8-flash-lite`, and `gemini-3.0-flash` to ensure uninterrupted inference during peak traffic.
- **Structured Risk Scoring:** Outputs clear JSON-backed risk scores (`0–100`), threat classifications, and actionable red-flag explanations.
- **One-Click Test Presets:** Built-in sample scenarios for instant testing and demonstration.

## 🛠️ Tech Stack
- **AI Engine:** Google Gemini API (Multimodal Inference & JSON Schema Output)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Zero-latency client architecture)
- **Hosting & Infrastructure:** Firebase Hosting
